# Cloud transcription: an optional paid provider plugin behind a per-run consent gate

#382 asks for transcription through a cloud service next to whisper.cpp, optional and simple for the person and the agent. The owner chose the first service and the consent rules on 2026-11-18 (epic #451, wave 24, question Q2). This ADR adds a decision; it does not change SPEC decision 10 (transcription is first-class, whisper.cpp is the default provider) or decision 39 (voiceover).

## Context (verified)

- `TranscriptionProvider` (`packages/plugin-api/src/index.ts`) has no notion of cost or of where the audio goes. Every provider so far runs on the machine: `whisper-cpp` (`plugins/whisper-cpp`), the shoot stand-in (`standInProvider`, `packages/core/src/shoot/session.ts`) and test fixtures.
- The speech side already has the cost gate: `SpeechProvider.free` / `estimate`, `ConfirmationRequired` with a `confirmation` token and `ConfirmationStale` (ADR 0034 decisions 12 and 20), the key from `OPENAI_API_KEY` only and every network text through `scrub` (decisions 6 and 24, `plugins/openai-speech`).
- The daemon loads a transcription provider in seven places, six of which send it audio: `transcribe` (`transcribeAsset`, which also re-transcribes short windows around over-long words, `recoverLongWords`), `transcribe.verify` (`verifyExport`), the shoot take job (`transcribeTake`), the voiceover misread check and captions (`verifyTakes` through `takeTranscription`), and `analyze` speech; the shoot readiness check loads the provider without sending audio.
- Projects pin `@frameshell/whisper-cpp` at the version they installed; pins made before this ADR lack any cost field.
- OpenAI's speech-to-text guide (read 2026-11-18): uploads are at most 25 MB; word timestamps (`response_format=verbose_json`, `timestamp_granularities[]=word`) exist only for `whisper-1`, which the guide marks deprecated with a shutdown on 2027-02-26; the `whisper-1` prompt holds at most 224 tokens. The public pricing page (https://developers.openai.com/api/docs/pricing, read 2026-11-18, no account) lists Whisper at $0.006 per minute.

## Decision

1. **Cloud transcription is an optional plugin.** whisper.cpp stays the default and the only path Frameshell installs by itself. The first cloud provider is `@frameshell/openai-transcription` (`plugins/openai-transcription/`, only `@frameshell/plugin-api`, cloned from the `openai-speech` layout), registering provider id `openai` (`contributes.transcriptionProviders`). A person picks it per call (`transcribe --provider openai`) or per project (`transcription.provider`).
2. **Plugin API: optional cost and place fields** on `TranscriptionProvider`, the speech shape: `free?: boolean`, `remote?: boolean` (the audio leaves the machine) and `estimate?(audio: { seconds }, options)` → `{ cost, currency, minutes? }`. All optional, so existing providers keep compiling. Unknown cost counts as paid (ADR 0034 decision 12): a provider with neither `estimate` nor `free: true` is paid at an unknown cost. `whisper-cpp` declares `free: true`; so do the stand-ins and fixtures. **Compatibility (confirmed by the owner, 2026-11-19):** the provider id `whisper-cpp` counts as local and free whatever its version, because projects pin versions older than this field. A trusted plugin runs with full access to the machine anyway (plugin trust), so this exception weakens nothing: the gate is consent for honest providers, not a sandbox.
3. **`transcribe` refuses until confirmed, every run.** When the provider is paid (an estimate above 0, or unknown cost) or `remote`, `transcribe` extracts the audio as usual, then fails with `ConfirmationRequired` before anything is sent. The message says that **the audio of the asset is uploaded** to the provider (unknown-cost providers: "may be sent off this machine and may cost money"), how long it is, and the estimated cost ("plus short re-checks", decision 6). Data: `{ provider, model, asset, seconds, cost, remote, confirmation }`. The call proceeds only with `yes` (CLI `--yes`); `confirmation` (the token of the refusal, a digest of provider, model, asset content hash and the cost in whole cents; not the audio source, exact length or printed cost, which change when an ingest finishes between the ask and the confirmed call) binds the run to what the person saw, and a mismatch fails with `ConfirmationStale`, as in ADR 0034. No consent is stored: the next run asks again. The upload is named in the refusal because the cost is not the only thing the person agrees to; the words of their recording leave the machine.
4. **What leaves the machine:** the 16 kHz mono WAV the host already extracts for transcription of one asset (`.frameshell/cache/audio/`), plus the language code and, as decoding context, the last words of the piece before (later pieces of a long file) or up to the last 40 transcript words before a `recoverLongWords` window (decision 6). Those words came from the service in the same run. No file names, project files, other transcripts or people.
5. **Key from the environment only** (ADR 0034 decisions 6 and 24 kept): `OPENAI_API_KEY`, read at each call, used only in the `Authorization` header, never in files, the journal, progress, error data or logs; every text built from the network goes through `scrub`, a hand copy of the `openai-speech` one with a parity test.
6. **Only models with word timestamps qualify.** Slice 1 allows and prices only `whisper-1` ($0.006 per minute, `MODEL_PRICES` with source URL and date). There is no model environment variable; `--model` naming anything else fails before upload. `gpt-4o-transcribe` and its mini sibling give no word timestamps and stay out. The estimate covers the first pass of the whole asset; `recoverLongWords` windows run inside the confirmed run and are not asked again. Each window is a few seconds; their number has no fixed bound (one per word longer than `LONG_WORD_S` whose audio shows speech after its head, nearby ones merged), so the refusal names them as "plus short re-checks" instead of pricing them.
7. **Word timing is the service's.** The plugin returns the words as the service times them and adds a `notes` sentence (shown in `transcribe`'s `warnings`): the times are coarser than whisper.cpp's DTW alignment and cut snapping or `transcribe --verify` should be trusted over them. `whisper-1` word entries carry no case or punctuation, so each word takes its spelling from the answer's `text` (matched in order within a few tokens, else the word as given); the service gives no word confidence.
8. **Other callers never upload.** `transcribe.verify`, shoot takes and their readiness check, the voiceover misread check and captions, and `analyze` speech take only a local free provider (`free: true`, no `estimate`, not `remote`, or `whisper-cpp`): with any other they refuse (`TranscriptionFailed`, the reason naming `transcribe --yes` and a local provider) or skip as each already does for a missing provider (voiceover verification `skipped`, analyze `speech.reason`, a failed take job). One daemon loader, `localTranscription`, is the only way they load a provider.
9. **Long files** are cut by the plugin into pieces under the 25 MB upload limit (10 minutes of 16 kHz mono 16-bit PCM is 19.2 MB), each cut moved to the quietest 100 ms of the 20 s before it, and the word times shifted back to the asset clock. The `remote` field (decision 2), the `whisper-cpp` exception and this cutting were confirmed by the owner on 2026-11-19.
10. **The app asks in a native box, with the daemon's own ask.** When `transcribe` refuses with `ConfirmationRequired` or `ConfirmationStale`, the app (main process) shows a warning box with the provider, the asset and its length in the title and, in the detail, that the audio of the file is uploaded (or may leave the machine, at an unknown cost), the estimated cost with the short re-checks of decision 6 and that the provider bills the person's own account. Buttons: "Upload and transcribe" and Cancel, Cancel being the default. Only a yes sends `transcribe` again with `yes` and the token of that ask; a `ConfirmationStale` asks again with a note that the file or price changed. The app stores no consent: every run asks again. One loop (`runConfirmed`, `apps/desktop/src/main/confirmation.ts`) serves this and the voiceover cost dialog (ADR 0034 decision 20). The paths that start a run for the person ask: the project setup transcription, the Shoot speaker search (declining ends it with "Transcription was not started") and the Transcribe button of the transcript view, shown for a not-transcribed asset only when the project's provider is not `whisper-cpp` (the app never starts whisper.cpp's download unasked, ADR 0034 decision 18). A decline in the setup is a soft stop, not a failure. Background paths (decision 8) never ask and never upload. No wire change.

## Slices

- **CT1 (this one):** decisions 1 to 9: plugin-API fields, the core gate and `transcribe` params `yes`/`confirmation` (`PROTOCOL_VERSION` bump), CLI `transcribe --yes [--confirmation]`, the local-only loader for the other callers, the plugin with stub-server tests, release wiring, skill and docs.
- **CT2:** decision 10, the app's cost and upload dialog (done).
- **Later:** a replacement for `whisper-1` before its 2027-02-26 shutdown (a model with word timestamps, or forced alignment of a timestamp-less transcript); other services as plugins of the same shape.

## Open questions for the owner

- SPEC §8.2 lists the transcription provider contract as `transcribe(file, opts)` only. Whether to add `free`, `remote` and `estimate` there (a SPEC change, so not made by this slice).

## Consequences

- A project whose `transcription.provider` is `openai` still transcribes nothing in the background: shoot takes fail, voiceover checks are skipped, `analyze` reports no speech, `transcribe --verify` refuses. The person picks `--provider whisper-cpp` for those.
- A third-party local transcription plugin must declare `free: true`, or its `transcribe` asks for confirmation and the background callers refuse it.
- OpenAI may change the price or retire `whisper-1`; the table states its date and the README says the usage page has the real bill.
