# Desktop app (Electron)

Nested: `src/main/CLAUDE.md` (main process), `src/renderer/src/preview/CLAUDE.md` (preview player). IPC surface main/renderer: `src/shared/api.ts`.

## Rules

- UI strings: never literal in components. Add to area file in `src/shared/i18n/`, English + Spanish (neutral Latin American, "tú"). Renderer `t`/`rich` in `src/renderer/src/i18n.ts`, main `src/main/language.ts`; parity test `test/i18n.test.ts`. e2e pin English (`--lang=en`).
- Playhead: one store, `src/renderer/src/preview/transport.ts`. Never keep a second playhead or play state.
- Selection: shared store `src/renderer/src/selection.ts`; extend, never duplicate.
- Panel code may run in detached panel window (ADR 0012). rAF, timers, observers, focus, fullscreen, `message`: take from element's own window (`ownerDocument.defaultView`). Global keys via `listenEverywhere`. Never `instanceof HTMLElement` on events or nodes: use `elementOf`/`isTag` (`src/renderer/src/windows.ts`).
- Renderer never writes project files: save via daemon `file.write`. Main only reads + watches. Only exception: Explorer Move to Trash (`src/main/trash.ts`, OS trash after confirm listing daemon `file.uses`).
- node-pty = N-API: no electron-rebuild. `scripts/prepare-native.mjs` fixes `spawn-helper` exec bit.
- Tooltips: one host in `App.tsx`, every project window. Controls set `data-tip` + `data-tip-key`, never native `title`. Shortcut text per platform via `shortcutLabel`, panel keys `PANEL_KEYS`.
- Context menus: one in-page menu mounted in `App.tsx`.
- Terminal optional: new project folds it (`DEFAULT_LAYOUT`, stored layout wins). No view, pty, AgentGuide until first shown (`opened` in `TerminalPanel.tsx`); then stays mounted. Anything needing a terminal calls `revealTerminal` (`Workspace.tsx`), never toggles. e2e `launch` seeds open terminal; `freshLayout: true` = new project (`e2e/terminal-optional.spec.ts`).
- Hand-off export menu (File > Export OpenTimelineIO / Premiere XML): ONE path. `HANDOFFS` table (command, menu id, extension, method, CLI name) + `pickHandoffExport` + one IPC `timelineExportHandoff` in main, `handoffNotice` in renderer; never a copy per format. Main save dialog, daemon writes, never renderer.
- Dialog keys + focus: `src/renderer/src/components/modal.ts`, shared by audition + voiceover.
- e2e stand-ins (`launch(box, { env, args })` in `e2e/harness.ts`; no model download, no cloud): `FRAMESHELL_SHOOT_STAND_IN=1` + `--use-fake-device-for-media-stream` (shoot, takes, teleprompter follow; live follow hears via `frameshellLiveHear`), never `--use-fake-ui-for-media-stream` for screen capture; `FRAMESHELL_SEGMENT_STAND_IN=1` (Pick); `FRAMESHELL_MATTE_STAND_IN=1` (matte track, subject preview); `FRAMESHELL_SPEECH_STAND_IN=1` / `paid` / `slow` (voiceover).
