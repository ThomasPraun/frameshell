# `frameshell` CLI

Thin client of the daemon: it starts `frameshelld` when none runs, acts on the project enclosing the current directory, and exits 0 (ok), 1 (command failed) or 2 (usage error); `proposal wait` also uses 3 to 6. Add `--json` to parse the output. Timeline commands take `--timeline <id>` (default `main`). `frameshell --help` lists every flag; this page says what each command is for and what to watch.

## Project

| Command | Use |
|---|---|
| `frameshell init [dir] [--name <name>] [--kind image]` | Scaffold a project: `frameshell.json`, empty `timelines/main.json`, `assets/`, `transcripts/`, `scripts/`, `compositions/`, and this skill under `.claude/skills/frameshell/` (`--no-skill` leaves it out). `--kind image` makes an image project (see [image-projects.md](image-projects.md)). Fails on an existing project. |
| `frameshell status` | Daemon, project, plugin trust, synced-folder warning, jobs, refused direct edits, open transactions. First command in a new session. |
| `frameshell doctor [--install] [--reprobe]` | ffmpeg/ffprobe and encoders; exit 1 with the fix when rendering is blocked. `--install` downloads the managed binaries. Also names the H.264 encoder renders use (VideoToolbox, NVENC, else x264: the first that encodes a 0.2 s test here, remembered per machine; `--reprobe` tests again), the machine's speed class (`fast`, `medium`, `slow`) with the proxy and draft sizes it suits, and the disk a master intermediate takes per minute at the project format. Also says which `frameshell` PATH runs and whether it is this CLI (a note, never an exit 1). |
| `frameshell import <file…> [--link] [--wait] [--source-url <url> --licence <id> --author <name> --title <t> --credit <line>]` | Copy media into `assets/` and ingest it (proxy, audio sidecar, waveform, thumbnails). `.svg` and font files (`.ttf`, `.otf`, `.woff`, `.woff2`) are not media: ingest only hashes them (MCP `asset_list` shows `kind` `svg` or `font`) and `clip add` refuses them. Without `--wait` it returns at once; `status` shows progress. A file from an outside source takes `--source-url`, `--licence` and `--author` (one source per call): they are recorded in `credits.json` (see [credits.md](credits.md)). |
| `frameshell credits` | Check the provenance of every asset the timelines place against `credits.json` and print the credit text for the video description. Exit 1 when any placed asset has no entry, no licence, a licence that needs credit without an author, changed content or a missing file. `--json`: `ok`, `assets` (`status`, `problem`), `credits`, `text`. |
| `frameshell credits set <asset> [--source-url <url>] [--licence <id>] [--author <name>] [--title <t>] [--credit <line>]` | Record where an asset already in `assets/` came from; `--licence own` for the person's own footage. Flags left out keep their value while the file is unchanged. |
| `frameshell skill update [--force]` | Update this project's copy of the agent skill (`.claude/skills/frameshell/`) to the installed Frameshell's version. An unedited older copy also updates when the project opens; `status` and `doctor` say when an edited copy was left alone. `--force` replaces Frameshell's files; files added to the folder stay. |
| `frameshell gc [--dry-run]` | Free disk: delete regenerable files under `.frameshell/` nothing uses (proxies, sidecars, waveforms, thumbnails, transcription audio, subject mattes of deleted or replaced assets; clip renders no clip keys; Chat about this captures in `.frameshell/context/` older than 7 days). `--dry-run` lists them first. Never touches `assets/`; deleted outputs rebuild on demand. |
| `frameshell script outline <file>` | Scenes (`## ` headings) of a Markdown script with their `scriptRef` anchors and linked clips, and for scenes with a `<!-- words: ... -->` comment the timeline span of their words. |
| `frameshell script check <file>` | Check a shoot script (`shoot: true`, see [shoot-scripts.md](shoot-scripts.md)): scenes with their lines (speaker, spoken words, cues, `[FREE: …]` slots) and expected lengths, speakers matched to `people.json`, `source.stale` when the original changed, and `warnings` to fix before recording. |
| `frameshell shoot status <script>` | Where a shoot is (see [shoot-scripts.md](shoot-scripts.md#takes)): each scene's state (`none`, `deviations`, `done`), chosen take and pending deviations; each take with how it said every line and its deviations (ids `d_…`, `accepted`); `next` scene; cues. `--json` for all fields. |
| `frameshell shoot add <script> <asset> [--scene <slug>] [--recorded-at <iso>]` | Link a recorded file as a take starting at a scene (default the first). Compared once the file has a transcript. Undo: `shoot discard`. |
| `frameshell shoot accept <script> <take> [<deviation>…] [--undo]` | Let deviations pass (default all of the take's). Only what the person asked for. `--undo` takes it back. |
| `frameshell shoot choose <script> <scene> <take\|default>` | Pick the take that goes into the cut for a scene; `default` = the newest covering it. |
| `frameshell shoot discard <script> <take> [--restore]` | Set a take aside, never chosen; `--restore` brings it back. |
| `frameshell shoot assemble <script> [<scene>…] [--no-snap]` | Build the first cut in the shoot's timeline (created when missing): each scene's chosen take in script order, restarts and pauses over 1.5 s cut out, edges snapped into pauses, clips linked to their scene. A scene already assembled is replaced in place, what follows moves; clips anyone else placed stay. One transaction: `frameshell revert <tx>` undoes it. |
| `frameshell people list` | Optional `people.json` (see [people.md](people.md)): who is who across files. Each person's links; `MISSING` ones with the reason (kept, ignored). `--json`: `people`, `dismissed`. |
| `frameshell people add <name>` | New person, id `p_…` generated; names are unique ignoring case. |
| `frameshell people rename <person> <name>` | `<person>` is an id or the exact name. Writes the new name into the transcript of each linked speaker. |
| `frameshell people remove <person>` | Remove the person and their links (names already written into transcripts stay). |
| `frameshell people link <person> (--speaker <transcript>[:<speaker>] \| --angle [<timeline>:]<group>:<angle> \| --face <asset>@<seconds>[:x,y])` | Link a transcript speaker (no `:speaker` = the whole transcript), a multicam angle or a face anchor. Linking a speaker writes the person's name into that transcript. One speaker, angle or anchor per person; the target must exist. |
| `frameshell people unlink <person> (--speaker … \| --angle … \| --face …)` | Remove one link, spelled as when linked; works when the target is gone. |
| `frameshell people scan [<asset>…]` | Find faces in videos (default: every video in `assets/`; pictures skipped), locally: 2 frames per second, a face detector then a recognizer, each face followed over time with a face print per second. Cached per file content in `.frameshell/people/` (regenerable, `gc` sweeps it): a scanned video is not decoded again. Takes about 5 minutes per hour of footage; runs as a `people` job. First run downloads about 39 MB. It links nothing to anyone. `--json`: `assets: [{asset, cached, samples, tracks, embeddings}]`, `warnings`. |
| `frameshell people ranges <person> [--on-screen] [--timeline id]` | Timeline spans where the person speaks (default) or is on screen, pauses under 0.5 s bridged, with the total. `--json`: `spans`, `total`, `warnings`. Spans are timeline seconds now: ripple-cut from the last span to the first. |
| `frameshell people suggest` | Suggested links, each `sg_…` id with a score and why: a speaker linked to nobody who sounds like a person's linked speakers (`speaker`), the face on screen while a speaker talks (`face-speaker`), a face nobody has (`face`, with who it looks like or nobody), a multicam angle linked to nobody (`angle`: the person named like it or a new one, its mic's voice, the face most on its screen). Faces only from cached `people scan` results. `hints`: what kept voices or faces from being compared, with the fixing command. First run downloads the speaker model (about 60 MB with its runtime) and takes a few seconds per transcript; later runs are cached. `--json`: `suggestions`, `hints`. |
| `frameshell people confirm <suggestion>… [--reject] [--person <person>]` | Apply suggested links (a speaker's name goes into the transcript, a face becomes a face anchor), or `--reject` dismisses them for good. Ids must be current suggestions. A suggestion naming nobody needs `--person`: an existing person, or a new name that adds them (an `angle` suggestion without it adds a person with the angle's name). An agent's confirmation is marked `by` on each link. |
| `frameshell matte <asset>` | The subject matte of a video (which pixels of each frame are the person in front), computed locally and cached per file content in `.frameshell/cache/mattes/` (regenerable, `gc` sweeps it); prints its path first. A grayscale video at proxy size, frame N = proxy frame N, white = the person. Estimated 1.5 minutes per minute of video (progress with an ETA); runs as a `matte` job and waits for the asset's ingest. First run downloads 0.5 MB (plus ONNX Runtime, 33 MB, if face detection never ran). Two people give one merged matte; thin hair strands and mic arms are often left out. Export, `frame` and the app's preview use it for tracks `track set --behind` puts behind a plate, and make it when missing; run it first so they start at once. `--json`: `matte`, `size`, `fps`, `frames`, `cached`, `seconds`. |
| `frameshell beats measure <asset> [--bpm n] [--reset-edits]` | The beat grid of a music file, measured locally (no download) and written to `beats/<asset>.beats.json` (see [project-model.md](project-model.md#beat-grid)): tempo, every beat in source seconds, which beat starts a bar, a confidence, the largest gap to the hits it matched. About 5 s for a 3-minute track, as a `beats` job; waits for nothing (without a finished ingest it decodes at 16 kHz and caps the confidence). `--bpm`: the tempo you expect, so a 60 BPM song stays 60 and not 120. The person's `edits` in the file are kept unless `--reset-edits`. Prints `LOW` when the grid may be double time or a bar off, with the tempi to try: set `edits.tempo` in the file or measure again with `--bpm`. Refuses silence or sound with no rhythm, no audio, and tracks over 10 minutes. `--json`: `file`, `bpm`, `meter`, `confidence`, `low`, `residualMs`, `alternatives`, `beatCount`, `cached`, `keptEdits`. |
| `frameshell beats show <asset>` | The grid with the file's `edits` applied: `bpm`, `confidence`, `low`, `beats` and `downbeats` in source seconds (`--json`: every one; `current` is false when the asset changed since it was measured, so measure again). Nothing on a timeline snaps to or reads a grid yet. |
| `frameshell style show` | Optional `style.json` (see [project-model.md](project-model.md#style)): the project's colours, fonts, type sizes, motion, sound levels, platforms, rules and banned list, each value with its source: written in the file (no mark), `(personality)` from its motion personality, or `(default)` (`not set` = not decided: ask the person). Safe zones of the platforms it names. Read it before making captions, cards or generated clips. `--json`: `style` (null without a file; every value `{ value, source }`), `from` (with `status`: `changed` = the user style was edited since it was copied), `safeZones`. |
| `frameshell style set <path> <value>` | Set one style value by the path `style show` prints (`colors.accent`, `type.hero`, `fonts.display`, `banned`); the value is JSON, else plain text; `null` removes it. Negative numbers after `--`. Prints every value that changed and `undo: frameshell revert <op>`; journaled, and held by review mode. Only with the person's agreement. |
| `frameshell style apply <name> [--replace]` | Copy a user style (`style list`) or a motion personality (`playful`, `premium`, `corporate`, `energetic`, `calm`) into `style.json`, value by value, printing each value that changed; `--replace` makes the file exactly that style. Journaled, held by review mode. |
| `frameshell style save <name> [--force]` | Keep the project's `style.json` as a user style on this machine for other projects (`--force` overwrites one of that name). |
| `frameshell style list` | User styles on this machine (an invalid one says why) and the motion personalities. |
| `frameshell mcp` | Serve the MCP tools on stdio (see [mcp.md](mcp.md)). |

## Timeline

| Command | Use |
|---|---|
| `frameshell timeline show` | Every track and clip: ids, `start`/`end` (timeline), `in`/`out` (source), speed. `--json` is compact on purpose. |
| `frameshell track list` | Tracks bottom to top (first video track = bottom layer). |
| `frameshell track add <video\|audio\|subtitles> [--name n] [--index n]` | New track, on top unless `--index`. Subtitle tracks need `--follows <track>`; `--preset big-keyword\|plain`, `--position top\|center\|bottom`, `--entry none\|chars\|words\|line`, `--keyword-color #rrggbb\|none`, `--keyword-scale 1-2`. |
| `frameshell track set <track> …` | Rename (`--name`, `--clear-name`); move in the stack (`--index n`, 0 = bottom layer); silence a video, audio or program track (`--muted`, back with `--unmuted`) or leave a video or program track's pictures out while its sound plays (`--hidden`, back with `--shown`), in export and preview alike; put a video track behind the person in front on a lower video track, a big word between the background and the head (`--behind <plate track>`, back with `--behind none`; in export, `frame` and the app's preview; the plate's matte is made when missing, about 1.5 min per min of video, and until then the preview shows the word in front with a note; keep the word 30-55 % covered and off the face; skip two-person shots; put b-roll cutaways above the word's track or below the plate, since a track between them covers the person and the word then shows in front; removing or moving the plate track clears it); subtitle `--follows`, `--preset`, `--position`, `--entry`, `--keyword-color`, `--keyword-scale`, and `--gap 12-15.5` (repeatable; no cue shows in that range) or `--clear-gaps`. `--format <id>` with style flags sets a subtitle track's captions in that format only (a format other than the primary, see `format list`), e.g. `--format 9x16 --position center`; `--reset` first drops that format's style. |
| `frameshell track remove <track> [--force]` | `--force` when it holds clips. |
| `frameshell captions set <track> (--text "…" \| --file path) [--from s] [--to s] [--replace]` | Hand-chunked captions with a keyword: one phrase per line, chunks split by `\|`, the one keyword between asterisks (`No need to \| open any \| *editor*`). See [transcript-editing.md](transcript-editing.md#subtitles). |
| `frameshell clip add <track> [asset] …` | Place media (`--start`, `--in`, `--out` or `--duration`, `--speed`), or an adapter clip (`--type hyperframes --source <html> --duration s --props '<json>'`). Overlay placement `--x --y --scale --opacity`. `--ripple` inserts, moving later clips right on every video, audio and program track; `--ripple-track <track>` (repeatable) limits that to the clip's track plus the named ones. `--snap` snaps media `in`/`out` into pauses. |
| `frameshell clip move <clip> [--start s] [--track t]` | Same length, new place; refused on overlap. |
| `frameshell clip trim <clip> [--in s \| --start s] [--out s \| --end s]` | `--in`/`--out` in source seconds, `--start`/`--end` in timeline seconds. Snaps like `cut`. `--ripple` moves later clips by the length change: the inverse of `cut`. `--ripple-track <track>` (repeatable) as for `clip add`. |
| `frameshell clip split <clip> --at s` | Left part keeps the id; the right part's id is in `changes.added`. The left part keeps the clip's dissolve and fade in, the right part its fade out, the new cut has none; both keep the keys. |
| `frameshell clip remove <clip>` | Leaves a gap; to close it use `cut`. |
| `frameshell clip key <clip> --prop x\|y\|scale\|opacity\|gain --at s [--value v] [--ease linear\|in\|out\|in-out] [--remove] [--clear] [--format <id>]` | Keyframe on timeline second `--at`, inside the clip; `--value` defaults to what plays there now. Same frame replaces. `--remove` deletes the key at `--at`, `--clear` (no `--at`) every key of `--prop`. Audio tracks take only `gain`. `--format <id>`: `x`, `y`, `scale` or `opacity` keys in that format only (they start from the clip's own); `--clear` with it moves the clip there as in the primary again. See [transitions.md](transitions.md). |
| `frameshell duck <track> --under <track>… [--depth dB] [--attack ms] [--release ms] [--threshold dBFS] [--gap s] [--level dB]` | Music under a voice: gain keys on the clips of audio track `<track>` that dip while someone speaks on the `--under` tracks (video or audio; see [transitions.md](transitions.md)). Defaults: depth 7 dB, attack 40 ms, release 450 ms, speech above -38 dBFS (`--threshold=-40`: a negative value needs the `=`), stretches closer than 0.6 s merged. `--level dB` first sets each clip's static gain so the music's loudness (EBU R128, measured once per file and cached) sits that many dB under the voice's (about 12 is a start); a clip with gain keys of its own is left alone. The settings stay in each ducked clip (`audio.duck`). One operation (one transaction with `--level`); run it again after edits. |
| `frameshell transition set --at s [--kind dissolve\|fade\|wipe\|push\|iris\|dip-cut] [--direction left\|right\|up\|down] [--origin x0,y0,x1,y1] [--duration s] [--track <track>…]` | Dissolve (default; sound crossfades) or fade (dip through black) at the clip edge at `--at`, 0.5 s by default, on every video and audio track that has the edge (`--track` limits). `wipe` and `push` move the picture the `--direction` way (default `left`), `iris` opens it in a circle from the centre of `--origin` (fractions of the frame), bottom video track only; `dip-cut` is a hard cut with the outgoing clip darkened over its last 3 frames (opacity keys); pick the kind by cause, `variety:` warnings flag repeats. A clip start or end with nothing butted fades in or out. Short material shortens it and adds a warning. See [transitions.md](transitions.md). |
| `frameshell transition remove --at s [--track <track>…]` | Clear the transition at that edge. |
| `frameshell marker add --at s --label l [--color red\|orange\|yellow\|green\|blue\|purple]` | A named point on the timeline clock (a hook, a beat to land on, a note for the person); `--at` snaps to the frame grid. Labels are unique in the timeline ignoring case. The new id (`m_…`) is in `changes.added`. Labels are never shaped like an id (`m_…`): a reference is the id when it matches one, else the label. A `cut` of every track moves markers after it with the material and removes markers strictly inside the range (`warning:` names them; a marker on the cut's first frame stays); a `--ripple` trim does the same for the material it removes, and `--ripple` inserts shift them like clip starts. A cut or ripple of only some tracks (`--track`, `--ripple-track`) leaves markers where they are. Markers paint and play nothing. |
| `frameshell marker set <marker> [--at s] [--label l] [--color c \| --clear-color]` | Move, rename or recolour one; `<marker>` is its id or its label. |
| `frameshell marker remove <marker>` | Delete one, by id or label. |
| `frameshell marker list` | Markers by time: id, `at`, label, colour (`--json`: `markers`). `timeline show` lists them too. |
| `frameshell tempo set (--clip <clip> \| --bpm n [--offset s] [--meter n] \| --clip <clip> --bpm n [--offset s])` | The timeline's beat grid (see [project-model.md](project-model.md#beat-grid)). `--clip`: follow the measured grid in the beats file of that media clip's asset (run `beats measure` on it first); the grid rides on the clip, so moving, trimming or speeding up the music moves it. `--bpm`: a nominal grid for blocking a film before music exists, beat `i` at `--offset + 60 i / bpm` seconds (default 0) with `--meter` beats to the bar (default 4); with `--clip` it rides on that clip and `--offset` is in the clip's source seconds. Replaces the whole tempo. Removing the clip clears it (`warning:`); splitting it keeps the tempo on the left part (`warning:`). The app draws bars stronger than beats, and dragged clips snap to them. |
| `frameshell tempo clear` | Remove the timeline's tempo. |
| `frameshell tempo show` | The stored tempo and its grid on the timeline clock: `bpm`, `bars` and `beats` in timeline seconds, `low` for a LOW confidence grid (`--json`: every beat). Says why there is no grid yet (no beats file for the clip, a broken one). |
| `--snap-to beat\|bar\|marker` (`clip add\|move\|trim\|split\|key`, `transition set\|remove`, `marker add\|set`, `cut`) | Move each time of the command to the nearest beat, the nearest bar start, or the nearest marker within 1 s (`cut --from 7.9 --to 12.2 --snap-to beat`); the history records the seconds it landed on. A `cut` or `clip trim` then lands exactly there (no pause snapping, so `--snap-window` is refused with it). Refused: `beat` and `bar` with no `tempo`, with a clip that has no beats file yet, with a LOW confidence grid (check `beats show`, set `edits`, or measure again with `--bpm`), and for a time far outside the music. `--snap-to` moves a time you already have to the nearest beat; to say "bar 8" outright, write `bar:8` (next row). |
| Time flags: `--at` (`marker add\|set`, `clip split`, `clip key`, `transition set\|remove`), `--from`/`--to` (`cut`), `--start`/`--end` (`clip add\|move\|trim`) | Seconds on the timeline clock, or a marker id or label with an optional offset: `--at hook`, `--at hook+0.5`, `--from intro --to outro-1`. The daemon turns the name into seconds before the change, against the timeline as it is at that moment (a marker added earlier in the same transaction counts), and the history records seconds. A label is tried whole first, so `end-card` is a label, not `end` minus `card`. An unknown name fails and lists the markers. `beat:N` and `bar:N` name the Nth beat or bar start counting from 1 in the music **file** (`beat:1` its first measured beat, `bar:1` its first downbeat; trimming the clip head never renumbers), with the same offset: `--at bar:8`, `--from bar:2 --to bar:6`, `--start beat:17-0.1`; `beat:2.5` is halfway between beats 2 and 3. They need a `tempo` (`tempo set`), and are refused on a LOW confidence grid, on a music clip with no beats file yet and N < 1, with the same messages as `--snap-to`; past the measured part they continue at the tempo. With a pickup `bar:N` is not `beat:(meter*(N-1)+1)`. A marker label shaped like `beat:8` or `bar:2` is refused. `word:` names are still refused. Source-clock `--in`/`--out` stay seconds. |
| `frameshell clip reframe <clip> [--format 9x16] [--person <id\|name> \| --anchor 0-1]` | Frame a video clip for another aspect (default 9x16, for reels) with a face in it: scales the picture to cover the frame (`transform.scale`) and positions it so the face sits centered and 30 % from the top, never showing outside the picture. Looks at 2 frames per second of the clip's own stretch of its file, follows the largest face and writes `x`/`y` keys only where it moves (a still stretch holds, a move glides with ease in-out); a face that never moves gives a static `transform` and no keys. `--person` follows that person's face from the cached `people scan` (the person's face linked) with no detection; `--anchor` (0 left edge, 1 right edge) fixes the picture's horizontal position, for footage with no face. Replaces the clip's `x`, `y` and `scale` (`warning:` says so); one transaction (`revert <tx>`), or one proposal in review mode. The frame is the export's: in a 16:9 project the preview shows the zoomed clip and a `vertical-1080x1920` export shows the framing (`warning:`). No face found: the clip is left as it was. Local, on CPU; the first run downloads the YuNet face detector, about 33 MB. Progress on stderr. `--json`: `follows`, `samples`, `faces`, `placement`, `keys`, `operations`, `tx`, `warnings`. |
| `frameshell clip verify <clip> [--probes n] [--tolerance 0-255]` | Check that a generated clip (a motion clip; any adapter with a live preview, `hyperframes` has one) paints a pure function of time. Loads its live page in headless Chrome at the project resolution and captures `--probes` frames (default 12, 2 to 48) at `(i + 0.37) x duration / n` of the played part, each twice: cold (a fresh page seeks straight to the time) and after a reseek (one page shows an unrelated probe first). A probe fails when a channel (red, green, blue, alpha) differs by more than `--tolerance` of 255 (default 2): the composition keeps state between frames (CSS transition, timer, clock, unseeded random, composited layer), so its render depends on paint order. Exit 1 then; `worst` names the probe time, the pixel and the page element that paints it. `distinct` counts different cold pictures; a `warnings` entry says when it is 1 (the clip never moves, or the timeline is not bound to the seek). Reads only: renders nothing and writes nothing, but takes up to a minute (a page load per probe) and needs the plugin trusted. `--json`: `ok`, `tolerance`, `size`, `probes` (`at`, `reseekFrom`, `max`, `pixels`, `ok`), `distinct`, `worst` (`at`, `max`, `pixel`, `element`), `warnings`. MCP: `clip_verify`. |
| `frameshell clip set <clip> …` | `--speed`, `--gain` (dB, negatives as `--gain=-6`), `--muted`/`--unmuted`, `--x --y --scale --opacity`, `--props '<json>'` (replaces), `--elements '{"#title":{"y":-40,"scale":1.2}}'` (adapter clips: merged per selector, `null` removes one; `--clear-elements` clears all), `--voice` (media clips: writes the voice chain of `style.json` `sound.voice` as explicit audio effects; with no style: high-pass 85 Hz, denoise floor -30 dB reduction 8 dB, compressor -20 dB 2.5:1 attack 8 ms release 140 ms makeup +2 dB), `--audio-effects '[{"kind":"highpass","frequency":90}]'` (replaces the list; kinds `highpass`, `denoise`, `compressor`, omitted numbers = the voice chain's) or `--clear-audio-effects`, `--glass` (generated clips on an upper track: copies `style.json` `glass` as the clip's `backdrop`; with no style: blur 46, saturate 1.45, dim 0.55; only when the style's `glass.cards` is true or the person asks), `--backdrop-blur <px>` `--backdrop-saturate <x>` `--backdrop-dim <0-1>` (one number each, merged, over `--glass`) or `--clear-backdrop`, `--script-ref <script#scene>`/`--clear-script-ref`. `--format <id>` (a format other than the primary, see `format list`) changes the clip in that format only, where its automatic layout is wrong: `--x --y --scale --opacity`, `--props` (generated clips; renders again for that format on export), `--elements`, `--hidden` (no picture there, its sound still plays; back with `--shown`); `--reset` first drops what that format had. Timing and sound are every format's, so `--speed`, `--gain`, `--muted`, effects, glass and `--script-ref` are refused with it. Check with `frameshell frame --at <s> --out <file.png> --format <id>`. |
| `frameshell multicam create <asset> <asset>… [--name <angle>…] [--mic-file <file>…] [--mic-name <n>…] [--sound <s>…] [--group-name n]` | One video file per camera or person. Measures every file's offset against **all the others** by audio cross-correlation (each file lands through its best match with a file already placed, so a faint camera syncs through the mic that hears the same room), adds a group, a program track and one `grid` shot over the cameras' length. Prints each file's offset, confidence and the file it matched; below 0.5 the file got no shared sound to match, is **not** shifted (offset as the reference, the first file with sound) and `warning:` says so: check it by watching or listening, then fix it with `multicam offset` (cameras) or `multicam mic` (mics). `--name` once per file in order (default: file name). | `frameshell format add <id> [--size WxH] [--index n]` | Deliver the same edit in another format: built-in `16x9` (1920x1080), `1x1` (1080x1080), `4x5` (1080x1350), `9x16` (1080x1920), or a custom id with `--size` (even), e.g. `frameshell format add web-1600x900 --size 1600x900`. In it, footage with no transform or keys fills the frame, cropped around the centre (a source with alpha on an upper track, such as a lower third, is fitted whole instead: no transform needed); generated clips render at its size on export; vertical captions are 1.3x larger. Journaled in your transaction: `history` lists it (`project config`, touched `format:<id>`), and `frameshell revert <op\|tx>` undoes it like a timeline change. While review mode is on it waits in your transaction's proposal like a timeline change (`frameshell proposal wait`). |
| `frameshell format remove <id>` | Remove a format (never the primary). |
| `frameshell inspect --at <s> (--point x,y \| --px X,Y) [--timeline id] [--segment] [--json]` | What a point of the frame shows: the clips under it (topmost first, which one is seen) and, in a generated clip, the DOM element painting it (selector, text, box, styles, file or React components, ancestors). `--point` takes fractions of the frame, `--px` project pixels. Use it to find what "the box at the top right" is before editing it, and to check the edit landed. Generated clips load in headless Chrome (a second or two each) and need a trusted project. `--segment`: in an image project, on a photo, also writes three mask PNGs of the part under the point (see [image-projects.md](image-projects.md)). |

## Plugins

| Command | Use |
|---|---|
| `frameshell plugin install <spec>` | `github:<user>/<repo>[#ref]`, `git+<url>[#ref]`, an npm name, or a local tarball from `npm pack` (`./name-1.0.0.tgz`; one from outside the project is copied to `vendor/`; pinned with its sha256: a changed file is never installed). Pins it in `frameshell.json` and links the skills it ships into `.claude/skills/`. |
| `frameshell plugin remove <name>` | Unpin, uninstall, unlink its skills. |
| `frameshell plugin list` | Plugins with status and what they contribute (commands, clip types, providers, presets, skills). |
| `frameshell <plugin> <command> …` | A plugin command, e.g. `frameshell hyperframes new intro --duration 8`. |

A project that declares plugins loads them only once trusted: commands needing them fail with `ProjectNotTrusted` until the user agrees and you re-run with `--trust`.
