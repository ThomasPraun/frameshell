# `frameshell` CLI

Thin client of the daemon: it starts `frameshelld` when none runs, acts on the project enclosing the current directory, and exits 0 (ok), 1 (command failed) or 2 (usage error). Add `--json` to parse the output. Timeline commands take `--timeline <id>` (default `main`). `frameshell --help` lists every flag; this page says what each command is for and what to watch.

## Project

| Command | Use |
|---|---|
| `frameshell init [dir] [--name <name>] [--kind image]` | Scaffold a project: `frameshell.json`, empty `timelines/main.json`, `assets/`, `transcripts/`, `scripts/`, `compositions/`, and this skill under `.claude/skills/frameshell/` (`--no-skill` leaves it out). `--kind image` makes an image project (see [image-projects.md](image-projects.md)). Fails on an existing project. |
| `frameshell status` | Daemon, project, plugin trust, synced-folder warning, jobs, refused direct edits, open transactions. First command in a new session. |
| `frameshell doctor [--install]` | ffmpeg/ffprobe and encoders; exit 1 with the fix when rendering is blocked. `--install` downloads the managed binaries. Also says which `frameshell` PATH runs and whether it is this CLI (a note, never an exit 1). |
| `frameshell import <file…> [--link] [--wait]` | Copy media into `assets/` and ingest it (proxy, audio sidecar, waveform, thumbnails). Without `--wait` it returns at once; `status` shows progress. |
| `frameshell gc [--dry-run]` | Free disk: delete regenerable files under `.frameshell/` nothing uses (proxies, sidecars, waveforms, thumbnails, transcription audio of deleted or replaced assets; clip renders no clip keys; Ask agent captures in `.frameshell/context/` older than 7 days). `--dry-run` lists them first. Never touches `assets/`; deleted outputs rebuild on demand. |
| `frameshell script outline <file>` | Scenes (`## ` headings) of a Markdown script with their `scriptRef` anchors and linked clips, and for scenes with a `<!-- words: ... -->` comment the timeline span of their words. |
| `frameshell mcp` | Serve the MCP tools on stdio (see [mcp.md](mcp.md)). |

## Timeline

| Command | Use |
|---|---|
| `frameshell timeline show` | Every track and clip: ids, `start`/`end` (timeline), `in`/`out` (source), speed. `--json` is compact on purpose. |
| `frameshell track list` | Tracks bottom to top (first video track = bottom layer). |
| `frameshell track add <video\|audio\|subtitles> [--name n] [--index n]` | New track, on top unless `--index`. Subtitle tracks need `--follows <track>`; `--preset big-keyword\|plain`, `--position top\|center\|bottom`. |
| `frameshell track set <track> …` | Rename (`--name`, `--clear-name`); move in the stack (`--index n`, 0 = bottom layer); subtitle `--follows`, `--preset`, `--position`. |
| `frameshell track remove <track> [--force]` | `--force` when it holds clips. |
| `frameshell clip add <track> [asset] …` | Place media (`--start`, `--in`, `--out` or `--duration`, `--speed`), or an adapter clip (`--type hyperframes --source <html> --duration s --props '<json>'`). Overlay placement `--x --y --scale --opacity`. `--ripple` inserts, moving later clips right on every video, audio and program track; `--ripple-track <track>` (repeatable) limits that to the clip's track plus the named ones. `--snap` snaps media `in`/`out` into pauses. |
| `frameshell clip move <clip> [--start s] [--track t]` | Same length, new place; refused on overlap. |
| `frameshell clip trim <clip> [--in s \| --start s] [--out s \| --end s]` | `--in`/`--out` in source seconds, `--start`/`--end` in timeline seconds. Snaps like `cut`. `--ripple` moves later clips by the length change: the inverse of `cut`. `--ripple-track <track>` (repeatable) as for `clip add`. |
| `frameshell clip split <clip> --at s` | Left part keeps the id; the right part's id is in `changes.added`. |
| `frameshell clip remove <clip>` | Leaves a gap; to close it use `cut`. |
| `frameshell clip set <clip> …` | `--speed`, `--gain` (dB, negatives as `--gain=-6`), `--muted`/`--unmuted`, `--x --y --scale --opacity`, `--props '<json>'` (replaces), `--script-ref <script#scene>`/`--clear-script-ref`. |
| `frameshell multicam create <asset> <asset>… [--name <angle>…] [--mic-file <file>…] [--mic-name <n>…] [--sound <s>…] [--group-name n]` | One video file per camera or person. Measures every file's offset against **all the others** by audio cross-correlation (each file lands through its best match with a file already placed, so a faint camera syncs through the mic that hears the same room), adds a group, a program track and one `grid` shot over the cameras' length. Prints each file's offset, confidence and the file it matched; below 0.5 the file got no shared sound to match, is **not** shifted (offset as the reference, the first file with sound) and `warning:` says so: check it by watching or listening, then fix it with `multicam offset` (cameras) or `multicam mic` (mics). `--name` once per file in order (default: file name). Only the first 10 minutes of each file are matched. **Separate mics:** `--mic-file` once per sound file (recorder, lavalier; any start time, audio-only is fine), `--mic-name` names them in order. `--sound` once per camera, in order: a mic number (1 = first `--mic-file`), `none` (wide camera, no sound) or `camera` (its own file's sound); default: camera n takes mic n while there are mics, the rest keep their own file. One mic may serve several cameras (it plays once); a mic nobody uses still plays. |
| `frameshell multicam gallery <asset> [--name <tile>…] [--group-name n] [--at s]` | One gallery-view call recording (Zoom, Meet, Teams). Finds the tile grid by its gutters on frames spread over the whole file and adds one angle per tile (a crop of the same file, rows top to bottom, each left to right; `--name` once per tile in that order, default `Tile 1`…), a program track and one `grid` shot. The file's sound plays once through the group mic `call`. Prints each tile's crop and confidence (below 0.5: `warning:`, fix with `multicam angle --crop-*`) and, when the layout changes mid-call, every stretch with its tile count and a warning with the time; the tiles follow the layout held longest, or the one playing at recording second `--at`. Refuses a file without a tile grid. `--json`: `tiles`, `layouts`, `confidence`, `mic`, `samples`. |
| `frameshell multicam offset <group> <angle> <seconds>` | Set one angle's offset by hand: the group second where its file's time 0 plays (absolute, not negative; smaller = that angle plays earlier against the others). To start an angle before the others, raise theirs. Refused when a shot would play past the group's new end: trim it first. |
| `frameshell multicam angle <group> <angle> …` | Change one angle: `--name`, `--crop-left`/`--crop-top`/`--crop-right`/`--crop-bottom` (fraction of the picture cut off that side, 0 to below 1; other sides keep theirs) or `--clear-crop`, its own file's sound under every shot `--gain dB`, `--muted`/`--unmuted`, where it is heard `--mic <mic id>`, `--mic camera` (its own file) or `--mic none`, `--screen`/`--no-screen` (a screen share: `direct` shows it while it moves, never as a speaker), and `--speaker s1` (or `--clear-speaker`): the transcript speaker whose words are this person's turns when people share a file or mic. An angle that takes a mic or none has no gain or mute of its own: set them with `multicam mic`. The angle id stays. |
| `frameshell multicam reframe <group> <angle> (--time s \| --at s) [--x f] [--y f] [--remove]`, `… --clear` | Where a tile cuts the angle's picture when their aspects differ (solo and two-up shots of a 9:16 export of 16:9 cameras): a key centering the cut on `--x`/`--y` (fractions of the source picture: 0 left/top, 1 right/bottom; omitted: the point there now, the crop's center without keys) from timeline second `--time` (mapped to the group second the program track plays then) or group second `--at`. A key in the same frame is replaced; the point moves in a straight line between keys and holds before the first and after the last; the cut never leaves the angle's crop. `--remove` deletes the key in that frame, `--clear` every key. Keys sit on the group clock, so cuts keep them. A 16:9 export of 16:9 cameras is not cut, so keys change nothing there; screens are never cut. |
| `frameshell multicam faces <group> [<angle>…] [--replace]` | Propose `reframe` keys from faces (see `multicam reframe`): looks at 2 frames per second of each named angle (default: every angle that is not a screen), follows the largest face inside its crop and writes keys only where it moves (a held position, a glide of at most 0.5 s to the next), one `multicam.reframe` operation per angle, all in one transaction. Angles that already have keys are skipped (`kept`) unless `--replace`; an angle with no face found keeps its framing (`warning:`). Local, on CPU (YuNet on ONNX Runtime Web); the first run downloads both, about 33 MB. Progress on stderr. `--json`: `angles: [{angle, name, samples, faces, keys, operation}]`, `kept`, `tx`, `warnings`. |
| `frameshell multicam paint <group> [<angle>] --from s --to s (--speaking [--alone] \| --silent \| --measured)` | Correct who speaks by hand, on the **group** clock: `--speaking` marks the angle as speaking from `--from` to `--to` (`--alone`: every other angle that can speak is marked silent there too, the person takes the floor), `--silent` as not speaking, whatever its sound says; `--measured` takes the range back to the measured turns (no `<angle>`: every angle). Painted turns live in the group (`groups[].painted`: `{angle, start, end, speaking}`), replace the measured turns of their angle for `multicam turns` and `direct` (so re-directing keeps them), and are undone like any operation. The app paints them on the program track's turn lanes. |
| `frameshell multicam mic <group> <mic> [--name n] [--offset s] [--gain dB] [--muted\|--unmuted]` | Change one separate mic: rename it, set the group second where its file's time 0 plays (absolute, not negative: fixes its sync) or its sound under every shot. `--gain` takes a negative value as `--gain=-3`. Mic ids are in `timeline show --json` under `groups[].mics`. |
| `frameshell shot set <shot> [--layout solo\|two-up\|grid\|screen\|pip] [--angles a,b] [--corner top-left\|top-right\|bottom-left\|bottom-right]` | Change a shot's layout and the angles it shows, in layout order. `screen` shows one angle whole (bars, never cropped); `pip` takes the screen angle first, then a person as an inset in `--corner` (default `bottom-right`, only for `pip`). With only `--layout screen\|pip` angles marked `--screen` lead. Only `--layout`: angles kept, cut, or filled from the group. Only `--angles`: the layout follows the count when it does not fit (1 `solo`, 2 `two-up`, more `grid`). Removes the director's `confidence`/`reason`: the shot is now yours. Timing stays: `clip split` first to change part of a shot. |
| `frameshell direct <group> [--template interview\|podcast-calm\|panel-dynamic] [--rules <file>] [--from s] [--to s] [--replace-human]` | Shots from who speaks, by rules, in one operation (angles marked `--screen` are measured for motion: `screen` while nobody speaks, `pip` with the speaker's inset while someone does): shortest/longest solo (`minShot`, `maxShot` with a cutaway to the listener or wide), two-up on quick exchanges and on two people talking at once, wide on silence and laughter, `cutLead` (the voice leads the cut), `weights` per angle id (0 = never shown alone). Rules: the template (default `interview`) with `director.json` at the project root, or `--rules`, on top. Same turns and rules, same shots. Each shot is replaced over the same group time, so cuts and gaps stay; `--from`/`--to` are timeline seconds. Shots the person chose in the app are kept unless `--replace-human`, so re-run it after their fixes. Prints the shots below 50% confidence (`--json`: `low: [{clip, start, end, shot, angles, confidence, reason}]`): watch those (`frames_strip`, preview) and fix them with `shot set`, e.g. hold a reaction after a punchline. |
| `frameshell multicam turns <group>` | Who speaks when: every angle's speaking turns on the group clock (offsets applied), from that angle's own mic. A voice heard in another person's mic (bleed, >12 dB below the loudest mic at that moment) is not that person's turn; people talking at once give overlapping turns; pauses under 0.5 s stay inside a turn, sounds under 0.3 s are dropped. Read-only. `--json`: `turns: [{angle, name, start, end}]` sorted by `start`, `duration`, `warnings` (an angle without sound has no turns), `speakers`. An angle's `audio.gain` counts toward the mic comparison, and an angle with a `mic` is measured from that mic (its offset and gain); a `mic: null` angle has no turns. Angles marked `--screen` have no turns while the group has a person and are never measured from speakers. Angles that hear the same file, angles that hear the same mic once its transcript has speakers (until then they speak together, as two cameras of one person do), and angles with a `--speaker`, take their turns from that speaker's words in that sound's transcript instead (`speakers` lists them; see [multicam.md](multicam.md#one-mic-for-several-people)). |
| `frameshell cut [track…] --from s --to s` | Remove a timeline range on every video, audio and program track (or the listed ones) and close the gap. Edges snap into audio pauses; `--snap-window s` widens the reach, `--no-snap` cuts exactly. |

Mutations print `revision · op <id> · tx <id>`, plus a `snapped … -> …` line per snapped edge and any `warning:`. In `--json`: `revision`, `operation.id`, `operation.tx`, `changes.added/updated/removed`, `snaps`, `warnings`.

## History

| Command | Use |
|---|---|
| `frameshell tx begin "<label>"` | Group the next operations of this session (every timeline) until commit or abort. Without it, a session's operations group until ~10 s idle. |
| `frameshell tx commit` | Keep them. |
| `frameshell tx abort` | Undo them all, or nothing when someone changed the same clips since (the error lists the conflicts). |
| `frameshell history [--since <tx>]` | Operations by transaction with author and touched ids; `--since` shows only what came after `<tx>`. |
| `frameshell revert <tx\|op>` | Undo a transaction or one operation as a new operation. Refused with the conflicting later operations when they touched the same clips: revert those first, newest first. |

`status` lists open transactions; one left open by a closed shell is ended with `FRAMESHELL_SESSION=<its session> frameshell tx commit` (or `tx abort`).

## Media, export, frames

| Command | Use |
|---|---|
| `frameshell transcribe <asset> [--language l] [--model m] [--provider p]` | Word-level transcript to `transcripts/`. Word ids stay stable across re-runs; human `edits` are kept, and so are speakers once found. |
| `frameshell transcribe --speakers <asset> [--people n]` | Who says each word (local speaker diarization): `speaker` (`s1`, `s2`…) on the transcript's words and a `speakers` list with names (`Speaker 1`… until someone renames them in the file). Needs a current transcript. `--people` when you know how many talk: more reliable than guessing. Re-running keeps each voice's id and name where it matches, and speaker corrections in `edits` win. First run downloads about 60 MB. |
| `frameshell transcribe --verify <export> [--timeline id]` | Re-transcribe an export and report words lost at cuts; exit 1 when any was. |
| `frameshell render [--preset p] [--out file]` | Export; waits for the job and prints progress on stderr. Pending generated-clip renders are awaited. |
| `frameshell frame --at <s> --out <file> [--preset p] [--format png\|jpg\|webp] [--quality 1-100]` | Write the composited frame at timeline second `s`, exactly as export renders it; the format follows the extension of `<file>` unless `--format`. Open it to look at it. In an image project this is the export: `--at 0`. |
| `frameshell inspect --at <s> (--point x,y \| --px X,Y) [--timeline id] [--json]` | What a point of the frame shows: the clips under it (topmost first, which one is seen) and, in a generated clip, the DOM element painting it (selector, text, box, styles, file or React components, ancestors). `--point` takes fractions of the frame, `--px` project pixels. Use it to find what "the box at the top right" is before editing it, and to check the edit landed. Generated clips load in headless Chrome (a second or two each) and need a trusted project. |

## Plugins

| Command | Use |
|---|---|
| `frameshell plugin install <spec>` | `github:<user>/<repo>[#ref]`, `git+<url>[#ref]`, an npm name, or a local tarball from `npm pack` (`./name-1.0.0.tgz`; one from outside the project is copied to `vendor/`; pinned with its sha256: a changed file is never installed). Pins it in `frameshell.json` and links the skills it ships into `.claude/skills/`. |
| `frameshell plugin remove <name>` | Unpin, uninstall, unlink its skills. |
| `frameshell plugin list` | Plugins with status and what they contribute (commands, clip types, providers, presets, skills). |
| `frameshell <plugin> <command> …` | A plugin command, e.g. `frameshell hyperframes new intro --duration 8`. |

A project that declares plugins loads them only once trusted: commands needing them fail with `ProjectNotTrusted` until the user agrees and you re-run with `--trust`.
